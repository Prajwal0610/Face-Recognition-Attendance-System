# 📸 Face Recognition Attendance System

A Python-based Face Recognition Attendance System that automatically identifies registered users and records their attendance with date and time.

## 📌 Project Overview

The Face Recognition Attendance System is designed to automate the attendance recording process using facial recognition technology. The system captures a person's face through a camera, compares it with registered training images, and records attendance when a matching face is detected.

## ✨ Features

- 👤 Face Detection and Recognition
- 📝 Automatic Attendance Recording
- 📅 Date and Time-based Attendance
- 📊 Attendance stored in CSV format
- 🖼️ Training images for registered users
- ⚡ Automated attendance process
- 🐍 Python-based implementation

## 🛠️ Technologies Used

- Python
- OpenCV
- Face Recognition
- Computer Vision
- CSV
- NumPy
